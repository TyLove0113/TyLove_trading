# 真實報價設定指示（Option A / C）

## 呢個做啲咩

程式原本用 yfinance 嘅 **COMEX 期貨（GC=F）**，同你 MT4 嘅 **現貨 XAUUSD**
差 US$20–35，所以你見到嘅價位永遠對唔上。

行咗下面任一方法之後，系統會改用**你券商自己嘅報價** ——
同你落單嗰個價完全一致，唔需要再估校正值。

---

## 方法一：MT4 EA（推薦先用呢個）

**為咩揀佢**：用返你現有 AXI MT4 戶口，唔使等開 MT5。

### 步驟

**1. 搵 Railway 網址**

去 Railway → 你個 project → Settings → Domains，
複製你嘅網址（類似 `https://tylove-trading-production.up.railway.app`）。

**2. 設定防偽 token（可選但建議）**

Railway → Variables → 新增：

| 名稱 | 值 |
|---|---|
| `GOLD_FEED_TOKEN` | 自己作一串，例如 `tylove2026gold` |

**3. 安裝 EA**

1. 開 MT4（桌面版）
2. 頂部選單：**檔案 → 開啟資料夾 → 資料目錄**
3. 入到 `MQL4\Experts\` 資料夾
4. 將 `TyLovePriceFeed.mq4` 複製入去
5. 返 MT4，左邊 **導航器** 右鍵 → **重新整理**
6. 應該見到 `TyLovePriceFeed`

**4. 允許 WebRequest（好重要，唔做一定失敗）**

1. MT4：**工具 → 選項 → 智能交易系統**
2. 勾 **「允許 WebRequest 嘅 URL 列表」**
3. 撳 **新增**，貼上你 Railway 網址（**只要 https://網域，唔要尾隨斜線**）
4. 確定

> ⚠️ 呢步唔做，EA 會靜靜咁失敗，Log 只會寫「WebRequest 錯誤 4060」。

**5. 掛上圖表**

1. 開一個 **XAUUSD M15** 圖表
2. 將 `TyLovePriceFeed` 由導航器拖落圖表
3. 彈出視窗 → **常用** 分頁：
   - **允許實時交易** ✅（必須勾）
   - 允許 DLL 匯入 ⬜（唔需要）
4. **輸入參數** 分頁：
   - `API_BASE` = 你嘅 Railway 網址（**要連 https://**）
   - `FEED_TOKEN` = 同步驟 2 一樣（冇設定就留空）
   - 其他保持預設
5. 確定

**6. 確認成功**

- 圖表左上角會出現狀態面板，寫住「✅ 報價成功：N 次」
- MT4 底部 **終端機 → 智能交易** 分頁會見到「✅ 已推 301 支 XAUUSD M15 K 線」

**7. 確認系統收到**

去你個網站嘅黃金頁，應該見到綠色橫幅：
「✅ 用緊你券商嘅真實報價」

## 方法二：MT5 Python 收集器

**前提**：要先有 AXI MT5 戶口（見下面「開 MT5 戶口」）。

### 步驟

1. Windows 電腦裝 MetaTrader 5 終端，登入 AXI MT5 戶口
2. 開一個 XAUUSD 圖表，拉到有 300 支以上歷史
3. 開 Command Prompt：

```
pip install MetaTrader5 requests
```

4. 改 `mt5_collector.py` 頭兩行：
   - `API_BASE` = 你嘅 Railway 網址
   - `FEED_TOKEN` = 同 Railway 一樣
5. 試一次：

```
python mt5_collector.py --once
```

6. 成功就長開：

```
python mt5_collector.py
```

> 💡 想 24 小時唔斷，就放喺 Windows VPS 度行（見下面）。
> 自己電腦一熄機就會停。

## 常見問題

**Q：EA 顯示「WebRequest 錯誤 4060」**
A：URL 白名單未加。返步驟 4。記住只填網域，唔要尾隨 `/`。

**Q：EA 狀態面板寫「失敗」但冇錯誤**
A：檢查 `API_BASE` 有冇打錯，同 Railway 有冇正常運行。

**Q：網頁橫幅一直紅色**
A：睇 `GOLD_FEED_MAX_AGE_MIN`（預設 30 分鐘）。超過 30 分鐘冇新 K 線
   就會自動回落 yfinance。檢查 EA 有冇停咗、MT4 有冇斷線。

**Q：MT5 收集器話「連唔到 MetaTrader 5」**
A：① MT5 終端有冇開住同登入？② 係唔係 Windows？

**Q：可唔可以兩個方法一齊行？**
A：可以，但冇必要。後推送嘅會覆蓋前者。

**Q：會唔會影響我自己手動落單？**
A：完全唔會。呢隻 EA **只讀報價、唔會落任何單** —— 佢淨係將價格推去你個網站。
   落單仍然 100% 由你本人喺 MT4 執行。

## 開 MT5 戶口（將來行 Option B 用）

1. 登入 Axi Client Portal（my.axi.com）
2. **Create New Account**
3. 平台揀 **MetaTrader 5**
4. 揀帳戶類型、槓桿、基準貨幣
5. 設定交易密碼（8–15 位，最少兩類字元）
6. 提交

**注意**：
- 唔需要重新交身份證明（profile 已驗證）
- MT4 唔可以「升級」成 MT5，要另開
- 資金唔會自動搬，要自己 Funds → Transfer Funds
- **建議先開模擬戶口試**：Client Portal → Demo 分頁 → 揀 MT5，唔使 KYC
